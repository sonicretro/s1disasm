# Sonic the Hedgehog (16-bit) Disassembly

For an overview of the folder structure, [refer to this page](https://info.sonicretro.org/SCHG_How-to:Disassembly_Folder_Structure#Sonic_1).

Also See: http://info.sonicretro.org/Disassemblies

To build this, use build.bat if you're a Windows user, or build.js otherwise ('node build.js'). The built ROM will be called 's1built.bin'.

The build script requires Node.js version 18 or later. Windows users do not need to install it themselves: build.bat will download a portable copy of Node.js automatically.
